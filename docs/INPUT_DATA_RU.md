# Локальные входные данные

Новостной корпус расширен: `news_orenburg_multisource.csv` содержит 28 900
заголовков МЧС и Оренбург Медиа за 2023–2024. Рядом находятся кеш страниц,
`news_orenburg_archive_audit.csv` (полнота 24/24 месяцев) и
`news_orenburg_multisource_manifest.json` (хеши/происхождение).
Исходный `news_orenburg.csv` сохранён. [Сбор и признаки](REGIONAL_NEWS_COLLECTION_RU.md).

Все входные файлы находятся в одной папке `data/inputs/`. Они уже перенесены на этом компьютере; скачивать их для запуска не нужно. Папка целиком исключена из Git. После клонирования репозитория на другой компьютер скопируйте эту папку отдельно: GitHub её не содержит.

Пути задаются относительно корня проекта. Названия файлов внутри ZIP менять не нужно: загрузчик читает единственный CSV из архива. Форматы и столбцы исходных данных сохранены.

## Проверка и запуск

Из активированного окружения `sber`, в корне проекта:

```bash
python scripts/check_inputs.py --profile full            # все локальные входы; без сети
python scripts/check_inputs.py --profile municipal       # только муниципальный блок
python scripts/check_inputs.py --profile national        # только национальный блок
python -m pytest tests -q                               # лёгкие проверки, без обучения
python scripts/verify_research.py                       # целостность и воспроизводимость
```

`make data` вызывает ту же проверку, если установлен Make. В текущей среде Make отсутствует; используйте команды Python выше.

Другие профили: `weekly`, `news`, `maps`, `audit`, `research`, `full`. Профиль `full` требует все входы перечисленных блоков и не требует резервных копий или фактов 2025 года. Полный машинный перечень — `configs/input_files.json`; источники и ограничения — [DATA_SOURCES_RU.md](DATA_SOURCES_RU.md).

`bash scripts/get_data.sh` оставлен для совместимости и тоже только проверяет локальные файлы. Автоматическое скачивание исходных таблиц удалено. `make foundation` отдельно может загружать веса моделей, если их нет в локальном кеше; для проверки входов он не нужен.

Старые манифесты запусков сохранены с первоначальными путями и хешами. `configs/input_migration.json` связывает старые пути с новыми; проверка целостности учитывает перенос. Контрольные суммы всех 23 перенесённых файлов совпали до и после переноса. Локальная квитанция переноса находится в `data/inputs/migration_manifest.json` и тоже исключена из Git.
