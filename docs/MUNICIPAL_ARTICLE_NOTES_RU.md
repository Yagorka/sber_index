# Что учтено из статьи СберИндекса

Источник: [«Проблема преобразований муниципалитетов для аналитиков: как мы упорядочили хаос», 11.10.2024](https://habr.com/ru/companies/sberbank/articles/849682/).

Статья подтверждает важные для проекта правила:

1. territory_id описывает территорию в постоянных границах. ОКТМО, название и тип могут меняться; сохранение ОКТМО не гарантирует сохранения границ.
2. Связывать внешние данные нужно с версией территории на соответствующий период. Справочник содержит годовые интервалы; точные месяцы изменений из него не следуют.
3. Объединять территории суммированием можно только для аддитивных показателей. Наши расходы на жителя требуют весов численности населения, а не суммы или простого среднего.
4. Административное преобразование может нарушить сопоставимость ряда. Его нужно проверять отдельно от экономического шока.

В проекте эти принципы уже описаны в MODELING_PLAN_RU.md. В новом новостном пилоте реализован поиск алиасов внутри региона по активной годовой версии справочника. Неоднозначность отмечается, неизвестные территории не подбираются по похожему названию. Это ограниченная реализация: она не восстанавливает точную дату преобразования и не обрабатывает все населённые пункты из полного текста новости.
