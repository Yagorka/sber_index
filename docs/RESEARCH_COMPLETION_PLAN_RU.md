# Доработка исследования после аудита 07.10.2026

Все новые эксперименты выполняются после просмотра теста 2024H2. Они являются
исследовательскими; исходный запуск и замороженные прогнозы сохраняются. Новый
независимый результат возможен только на ещё не использованных фактах.

| Работа | Проверяемый результат |
|---|---|
| Сильные базы | Сравнения с национальным сезонным правилом, простым ансамблем, регуляризованным сезонным трендом и явно сезонным Prophet на общей подвыборке |
| Временной протокол | Аудит доступности параметров; последовательные веса только по зрелым прошлым ошибкам; явный fallback при отсутствии меток h=12 |
| Интервалы | Отдельные ошибки калибровки, исключённые из подбора весов; покрытие, ширина и доступность по месяцам и категориям |
| Внешние данные | Недельные маркетплейсы с лагом публикации; официальные события для проверки; инфляция только для экономической интерпретации |
| Детекторы и действие | Простая пороговая база; коррекция прогноза после тревоги; событие, пропуск и тревога без события в реестре |
| Содержательные выводы | Категории, регионы, относительные ошибки, доля выигравших МО, анализ общепита и маркетплейсов |
| Воспроизводимость | Полные версии пакетов; проверка среды, входов и прогнозных массивов; воспроизведение сохранённых метрик |
| Материалы | Единая гипотеза, границы выводов, сценарий использования; отчёт, слайды и демонстрация |
| Критерии | Таблица «требование → свидетельство → ограничение»; баллы только после получения официальной шкалы |

Публикация репозитория и независимая временная отметка требуют внешнего места
публикации. Локальный SHA256 подтверждает целостность, но не время создания.
Официальный baseline и баллы нельзя восстанавливать по работам других участников.

## Итог выполнения

Основные эксперименты и материалы выполнены: см. `tracking/research_completion.json` и [результаты](RESEARCH_AUDIT_RESULTS_RU.md). Ожидаются настройки baseline, новые муниципальные факты и место публикации. Установка зависимостей с нуля и независимая внешняя временная отметка не проверены. Публичные frozen-файлы защищены от неявной перезаписи; отличающийся новый вариант сохраняется отдельно.

## Новостной пилот выполнен

По Оренбургской области собраны 28 900 уникальных заголовков МЧС и Оренбург Медиа за 2023–2024. JSON-архив скачан requests + BeautifulSoup; все страницы за 24 месяца получены. Проверены семь прогнозных вариантов и три детектора с новостным входом; добавлены экономические темы и направления. Контрольная модель улучшилась на коротких горизонтах, на h=6 ухудшилась; основной ансамбль точнее. Бинарный новостной вход детекторов насыщается и совпадает с контролем покрытия. Код, конфигурация и [отчёт](REGIONAL_NEWS_IMPACT_RU.md) сохранены. Лёгкая среда сбора новостей установлена с нуля и проверена на всём кеше; установка полной модельной среды с нуля остаётся непроверенной. Региональный эксперимент не заменяет независимую оценку по России.
