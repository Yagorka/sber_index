# Внешние данные

Расширенный корпус новостей: `news_orenburg_multisource.csv`, 28 900 уникальных
заголовков за 2023–2024 по Оренбургской области. Источники — МЧС и
[Оренбург Медиа](https://orenburg.media/); новый архив получен через JSON API,
все страницы 24 месяцев скачаны. Исходная выборка МЧС сохранена отдельно.
Парсер requests + BeautifulSoup, конфигурация `configs/news_archive.json`.
Дата публикации берётся из `date_gmt`; first_seen — сбор в 2026 году;
история редактирования неизвестна. [Покрытие, темы, кеш и дополнительные признаки](REGIONAL_NEWS_COLLECTION_RU.md).

| Файл | Что это | Источник | Доступность во времени |
|---|---|---|---|
| `cbr_key_rate_daily.csv` | Ключевая ставка Банка России, % годовых, по дням | https://www.cbr.ru/hd_base/KeyRate/ (скачано 04.10.2026) | значение на дату вступления в силу |
| `cbr_key_rate_changes.csv` | Только даты изменения ставки, `delta_pp` | то же | `available_at = effective_date` — консервативно: объявление не позже вступления в силу |
| `event_registry.csv` | 7 датированных событий в регионах/МО (паводки, теракты, обстрелы) | ссылки в колонке `source_url` | `published_at = event_date` (новости в день события) |
| `cbr_key_rate_source.html` | Исходная страница ЦБ (для проверки разбора) | cbr.ru | — |

Реестр — не новостной корпус: это короткий список событий с проверяемыми ссылками.
Сопоставление с МО делается по `mo_name` внутри перечисленных регионов. Белгорода, Курска и Суджи в панели из 2016 МО нет (оценка не прошла порог качества СберИндекса), а для Севастополя, Дербента и Махачкалы сопоставление по названию не нашло МО; такие события попадают в отчёт как `matched=0`, а не подгоняются.

Все входные файлы, включая муниципальные расходы СберИндекса (CC BY-SA 4.0), находятся в `data/inputs/` и в репозиторий не включаются. `make data` проверяет локальные файлы без скачивания. Список — [INPUT_DATA_RU.md](INPUT_DATA_RU.md). Цитирование: «Потребительские безналичные расходы на уровне
муниципальных образований по категориям трат. СберИндекс. Данные доступны по адресу
https://sberindex.ru/ru/research/data-sense-opisanie-nabora-dannikh-khakatona-sberindeksa-po-munitsipalnim-dannim
(данные скачаны 04.10.2026)».

Геометрии МО (`data/inputs/municipal_boundaries.gpkg`, 74 МБ) в репозиторий не включены; они нужны только для карты в `make_figures.py` и берутся из набора границ СберИндекса: https://sberindex.ru/ru/research/dataset-borders-and-changes-of-Муниципалитетов.

## Доработка 07.10.2026

`verified_event_cases.csv`: три внешних события с подтверждающими публикациями МЧС; даты события и публикации разделены. Оценимы Орск и Красногорск, оба относятся к калибровочному периоду. Уссурийск сопоставлен, но длины истории недостаточно. Эти события не являются подтверждёнными метками сдвига расходов. Источники сохранены в CSV.

`cpi_december_2024.csv`: четыре национальных индекса Росстата, декабрь 2024 к декабрю 2023; публикация 15.01.2025. Используются для интерпретации двух широких категорий, а не как доступный в 2024 прогнозный признак. Источник: https://rosstat.gov.ru/storage/mediabank/1_15-01-2025.html.

Исходный реестр `event_registry.csv` сохранён для воспроизведения старых опытов. Его даты публикаций не все независимо проверены; в частности, ссылка EV03 датирована 08.08.2024 при указанном published_at 06.08.2024. Старые новостные результаты считаются диагностическими. В NewsFeatures доступность теперь определяется максимумом дат события и публикации.
