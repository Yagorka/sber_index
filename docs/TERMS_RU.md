# Как читать результаты проекта

В отчётах используются понятные названия вариантов. Короткие английские ID остаются в CSV и конфигурациях, чтобы код и сохранённые эксперименты продолжали работать.

| Термин | Что означает |
|---|---|
| MAE | На сколько рублей в среднем прогноз отличается от фактических расходов. Меньше — лучше. |
| WAPE | Сумма абсолютных ошибок, делённая на сумму расходов. Позволяет сравнивать категории разного размера; 0,10 означает 10%. |
| Bias, средняя знаковая ошибка | Прогноз минус факт, усреднённый по наблюдениям. Плюс — систематическое завышение, минус — занижение. |
| Горизонт, h | Через сколько месяцев после составления прогноза оцениваются расходы. h=3 — прогноз на три месяца вперёд. |
| Период подбора, validation | Январь–июнь 2024. На нём выбираются настройки и варианты признаков. |
| Проверочный период, test | Июль–декабрь 2024. На нём оценивается выбранный вариант. Повторные эксперименты после просмотра этого периода считаются исследовательскими. |
| Момент составления прогноза, origin | Последний месяц данных, доступный модели. Позднейшие расходы и новости использовать нельзя. |
| Тональность, sentiment | Позитивные, негативные, нейтральные, смешанные или неизвестные последствия новости для жителей. Негативная новость не обязательно означает рост цен. |
| Поправка без новостей | Коррекция базового прогноза по прошлым расходам, сезонности и уже известным ошибкам модели. |
| Только количество новостей | Вариант, использующий количество подходящих публикаций, без их тональности и направлений цен/доходов. Нужен, чтобы отделить пользу содержания от объёма новостного потока. |
| Новости с учётом давности | Оценки новостей складываются, причём старые публикации имеют меньший вес. Если новых событий нет, влияние постепенно уменьшается. Раньше этот вариант назывался «затухающая масса». |
| Доли новостей с учётом давности | Доля негативных/позитивных сообщений среди подходящих публикаций. Старая единственная негативная новость может сохранять долю 100%, хотя вес самой новости уже мал. |
| Срок уменьшения веса вдвое | Проверены 14, 30 и 90 дней. Для срока 30 дней вес события через 30 дней равен половине начального, через 60 — четверти, через 90 — одной восьмой. |
| Доля применяемой поправки, shrink | Какая часть рассчитанной коррекции применяется к прогнозу. 0 — прогноз сохраняется; 0,25 — применяется четверть поправки. |
| Регуляризация Ridge, alpha | Ограничение величины коэффициентов поправки. Чем больше alpha, тем сильнее ограничение. |
| Bootstrap и 95% интервал | Повторный расчёт разности ошибок на случайных выборках месяцев или муниципалитетов. Показывает неопределённость оценки. Интервал, включающий ноль, не подтверждает преимущество одного варианта. |
| Парное сравнение | Два варианта оцениваются на одних и тех же муниципалитетах, категориях и месяцах. |
| Ablation, отключение компонента | Проверка, как меняется ошибка, если убрать новости, национальные данные или часть моделей. |
| Ensemble, ансамбль | Объединение прогнозов нескольких моделей с выбранными весами. |
| Zero-shot | Готовая модель строит прогноз без дообучения на данных этого проекта. |
| Covariate, дополнительный признак | Данные, которые помогают прогнозу помимо самого ряда расходов, например национальная динамика. |
| Калибровка интервалов | Настройка диапазона прогноза по ранее наблюдавшимся ошибкам. |
| Уже известная ошибка | Разница прогноза и факта, когда целевой месяц уже завершился и данные получены. Раньше использовалось выражение «созревшая ошибка». |

Пример учёта давности: сегодня опубликована негативная новость с начальным весом 1. При сроке уменьшения веса вдвое 30 дней она даёт 1 условную единицу негативного сигнала сегодня, 0,5 через месяц, 0,25 через два месяца. Несколько событий складываются. Перед подачей в Ridge большие суммы дополнительно уменьшаются логарифмом, чтобы многочисленные публикации не подавляли остальные признаки. Это математическая обработка, а не оценка силы экономического эффекта новости.

Разность MAE в таблицах сравнения рассчитывается как ошибка новостного варианта минус ошибка контрольного. Отрицательное значение — новостной вариант точнее. В отчёте разбора ошибок столбец «снижение ошибки» имеет обратный знак: положительное значение означает улучшение; это явно указано рядом с таблицами.
